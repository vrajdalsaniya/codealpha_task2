## Proxima Project Management System

A full-stack project management application built using:

- Node.js
- Express.js
- MongoDB
- JavaScript
- HTML
- CSS

### Features

- User Authentication
- Project Management
- Task Management
- Comments System
- Real-time Updates
- Responsive Design

### Installation

```bash
npm install
npm start
```
